EUC Score package (user experience tests on Windows)
Checking…

Download Install-EUCScoreBase.zip from eucscore.com yourself and upload it here. Uploading it means you accept the EUC Score Subscription Agreement; organizations with more than 50 users or over US$1M revenue need a paid subscription. Templates built with "Include EUC Score" install it silently to C:\EUCScore and keep the vdi user logged on, because its tests need a desktop session.

Upload ISOs to Proxmox first. Any existing Proxmox template can be used for a batch.

Batches

Ramp-up spreads the desktop start times, so you can see where performance drops as load builds. Boot storm ignores these numbers. Density steps repeat the run on a growing number of desktops and give a report that says how many desktops the storage supports. For Fill disk, Duration is the time limit, so raise it for large fills.
